# Первый этап без DNS: панель и прямой REALITY

`scripts/bootstrap-direct.py` — отдельный этап для Ubuntu 24.04 amd64 (Python 3).
Устанавливает официальный 3X-UI **v3.10.0**, проверяя SHA-256 установщика.
Официальный установщик проверяет контрольную сумму архива релиза.

```bash
sudo python3 scripts/bootstrap-direct.py --server-ip YOUR_SERVER_IPV4
```

Панель слушает `127.0.0.1:2053`. Служба подписок отключена. Создаётся один
VLESS/TCP/REALITY-клиент с Vision на внешнем TCP-порту 8443; порт 443 остаётся
свободным для последующей настройки HTTPS/CDN. DNS и сертификат домена не нужны.
Fail2ban, UFW, Nginx и дополнительные транспорты этот этап не устанавливает и
не перенастраивает. При наличии внешнего firewall разрешите выбранный direct-порт.

Параметры: `--panel-port`, `--direct-port`, `--target` (TLS 1.3 hostname).
Внутренние API-запросы обходят переменные HTTP proxy. В конфигурации панели
используется транспорт `tcp`: alias `raw` в 3X-UI 3.10.0 теряет flow Vision.

Для уже установленной официальным установщиком v3.10.0 панели:

```bash
sudo python3 scripts/bootstrap-direct.py --server-ip YOUR_SERVER_IPV4 --adopt-official
```

Нужен root-only `/etc/x-ui/install-result.env`. Версия и порт проверяются;
неподдерживаемая установка не перезаписывается. Существующий одиночный REALITY
на выбранном порту сохраняется вместе с UUID, ключами и ссылкой. Другой протокол
или несколько клиентов на этом порту приводят к отказу до изменения настроек.
Перед API-изменениями создаётся согласованный SQLite backup.
При незавершённой настройке пакетов свежая установка останавливается до запуска
официального скрипта; состояние dpkg также проверяется после него.

Реквизиты остаются в `/etc/x-ui/install-result.env`; состояние и ссылка —
`/etc/3xui-varon/bootstrap.json` и `direct-main.txt`, права 600. Скрипт выводит
SSH-туннель, локальный URL панели и ссылку импорта. Повторный запуск не создаёт
нового клиента. Этот этап не запускает основной `bin/varon install`: тот требует
чистую машину и не является миграцией для установленной панели.

Проверки: `python3 -m unittest discover -s tests -v`, `bash tests/test-bootstrap.sh`.
Серверная проверка HTTPS через REALITY не доказывает доступность через ТСПУ:
финальная проверка выполняется на клиентском устройстве пользователя.
