# 3Xui Varon

Новый установщик для чистого Ubuntu 24.04. Основан на актуальном официальном
3X-UI, не на старом автоскрипте.

Сейчас работа ведётся в ветке `codex/modern-installer`. Первый запуск будет на
чистом тестовом сервере; до этого ветка не считается готовым production-релизом.

## Что делает

- Проверяет Ubuntu 24.04, DNS двух имён и свободные порты 80/443 до изменений.
- Устанавливает зафиксированный и SHA-256-проверенный официальный релиз 3X-UI.
- Настраивает один порт `443`: VLESS Reality, VLESS XHTTP и Trojan gRPC.
- Создаёт одного клиента с `subId` и единой подпиской, содержащей все три варианта.
- Выпускает сертификат Let's Encrypt для панели и подписки.
- Прячет панель и службу подписки на `127.0.0.1`; снаружи видны лишь SSH, 80 и 443.
- Включает UFW, Fail2ban: 3 ошибки SSH за 10 минут → бан на сутки, и unattended-upgrades.
- Не меняет существующую 3X-UI установку: предназначен только для чистой машины.

## DNS до запуска

У бесплатного DNS-провайдера создайте две `A`-записи на IPv4 сервера:

- `vpn.<ваш-домен>` — панель и подписка;
- `reality.<ваш-домен>` — Reality.

Имена произвольные; `vpn` и `reality` — только примеры. IPv6 не нужен, если вы
не создаёте AAAA-записи: иначе они тоже должны вести на этот же сервер.

## Проверка без изменений

```bash
sudo ./bin/varon preflight \
  --base-domain example.free-dns.tld \
  --panel-subdomain vpn \
  --reality-subdomain reality
```

## Установка

Интерактивный режим сам спросит домен, поддомены и e-mail для Let's Encrypt:

```bash
sudo ./bin/varon install
```

Если не нужен e-mail для уведомлений Let’s Encrypt:

```bash
sudo ./bin/varon install --no-email
```

Либо все значения можно передать флагами:

```bash
sudo ./bin/varon install \
  --base-domain example.free-dns.tld \
  --panel-subdomain vpn \
  --reality-subdomain reality \
  --email you@example.net
```

После завершения скрипт выводит URL панели и один URL подписки. Пароль панели не
пишется в консоль: он хранится только у root в `/etc/3xui-varon/panel.env`.

## Проверки разработчика

GitHub Actions выполняет Bash syntax check, ShellCheck и тесты генераторов на
Ubuntu 24.04. Живой тест всегда нужен на отдельном чистом сервере.

Старые `x-ui-latest.sh`, `x-ui-patch.sh` и инструкции из исходного форка не
являются частью нового установщика и не должны запускаться вместе с ним.
